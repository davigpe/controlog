# 🔭 Roadmap

Funcionalidades e melhorias planejadas para as próximas iterações do projeto:

* Rastreamento de entregas em tempo real para o cliente final (hoje o acompanhamento de status é feito só pelo gestor, pelo dashboard)
* Notificações automáticas de mudança de status do pedido, além da confirmação e do lembrete via WhatsApp já implementados
* Relatórios de gestão mais detalhados, com exportação (CSV/PDF) e comparação entre períodos
